# Agent 365: control with context

The user confirmed this brief in the authoring session:

- Approximately 60 seconds, 1920 x 1080, 30fps, English narration.
- Eight editable PowerPoint slides.
- A runnable public-evidence-grounded Agent 365 SWE specialist in the existing
  GitHub Copilot/VS Code host, not a newly deployed Microsoft cloud service.
- Audience: engineering leaders and implementers.
- Clean white/ink/blue editorial design; no stars, glow, fabricated logos, or
  claim that this is an official Microsoft template.
- Public Microsoft evidence only. Local English speech, no external narration
  transfer. The complete script must be approved before synthesis.
- Outputs are review candidates. Content, voice/listening, style, rights, and
  release acceptance are distinct decisions.

The narrative follows an illustrative operations agent: who owns it, what can it
access, and how can an operator trace its actions? Observe, govern, and secure
answer those questions. The ending proposes a bounded pilot, not tenant changes.

The requested current-date cutoff is 2026-09-21. Source revision dates are on or
before that date. Retrieval timestamps use the actual environment clock and are
not treated as publication or availability evidence.

No tenant is connected. No Entra objects, permissions, Azure resources, Agent 365
registrations, or licenses are created. Local coding-agent execution does not
establish Agent 365 service integration or a2swe DomainReady certification.
