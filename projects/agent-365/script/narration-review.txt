# CHAPTER 1 One agent. Three questions.
An operations agent can answer questions|and call tools.
But who owns it, what can it access,|and how do you trace its actions?
# CHAPTER 2 The control plane
Microsoft Agent 365 is the control plane|for observing, governing, and securing agents.
It is not the agent builder or runtime.
# CHAPTER 3 Observe
Observe: bring inventory and activity into view,|then trace agent invocations and tool calls.
# CHAPTER 4 Govern
Govern: establish ownership, identities,|permissions, and lifecycle controls.
# CHAPTER 5 Secure
Secure: connect identity, data protection,|and threat detection through Entra,|Purview, and Defender.
# CHAPTER 6 Extend what you built
When code-level integration is needed,|add only the SDK capabilities required.
Keep your existing framework and hosting.
# CHAPTER 7 Start with evidence
Start with one accountable pilot.
Verify licensing and preview limitations,|test the controls, then expand with evidence.
