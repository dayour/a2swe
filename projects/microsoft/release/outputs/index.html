Executive decision-makers

Microsoft: map needs to the right layer

Bottom line: Microsoft is a portfolio, not one system; first map the need to Windows, Microsoft 365, Azure or Copilot, then verify entitlements early.

Decision: Map needs to the right layer and confirm entitlements before committing.

Section 1

1. Windows is the PC layer

Start with Windows when the decision is the PC experience: devices, desktop, apps and user productivity. It anchors the endpoint for users, not every cloud service.

Supported claims

  • Windows 11 is the client operating-system layer for PC experience and user productivity. [ev-01] [ev-02]
  • The selected sources describe separate product layers: Windows, Microsoft 365, Azure and Copilot Chat. [ev-01] [ev-04] [ev-05] [ev-07]

Assets

Speaker notes

Evidence: Windows 11 is described as a client operating system with productivity-oriented features. Interpretation: treat it as the endpoint layer before expanding into cloud or AI choices.

Section 2

2. Microsoft 365 is work

Use Microsoft 365 when the need is everyday work: Office apps, email, files, meetings, sharing and collaboration. It packages work services, not custom infrastructure.

Supported claims

  • Microsoft 365 combines Office apps with online services for email, file storage, collaboration and meetings. [ev-03] [ev-04]
  • The selected sources describe separate product layers: Windows, Microsoft 365, Azure and Copilot Chat. [ev-01] [ev-04] [ev-05] [ev-07]

Assets

Speaker notes

Evidence: Microsoft 365 for enterprise combines Office apps with online services for email, storage, collaboration and meetings. Interpretation: this is the work-productivity layer.

Section 3

3. Azure builds apps

Use Azure when applications need cloud services: compute, storage, data and AI categories. It is the builder layer for apps and managed resources for teams.

Supported claims

  • Azure is the cloud-services layer for building and managing applications, including AI, compute and storage categories. [ev-05] [ev-06]
  • The selected sources describe separate product layers: Windows, Microsoft 365, Azure and Copilot Chat. [ev-01] [ev-04] [ev-05] [ev-07]

Assets

Speaker notes

Evidence: Azure documentation supports building and managing applications and lists AI, compute and storage categories. Interpretation: use Azure for application service needs.

Section 4

4. Copilot assists workflows

Treat Copilot as AI assistance that sits inside selected workflows and licenses. Confirm access, grounding, service availability and subscription before commitments.

Supported claims

  • Copilot Chat provides AI assistance to eligible Microsoft 365 users for information, content and tasks. [ev-07] [ev-08]
  • Copilot capability and grounding depend on access point, service capacity and Microsoft 365 Copilot licensing. [ev-09] [ev-10]

Assets

Speaker notes

Evidence: Copilot Chat helps eligible users find information, create content and complete tasks; grounding depends on access point and licensing. Interpretation: confirm entitlement before rollout.
