# Qualifications and safe-use boundaries

Access date: 2026-09-18.

## Fact qualifications

1. Release plans are directional. Microsoft states that 2026 release wave 1 covers April 2026 through September 2026, but also states that delivery timelines and projected functionality may change or may not ship. Use release-plan content as roadmap context, not as proof of availability. Source: https://learn.microsoft.com/en-us/power-platform/release-plan/2026wave1/
2. Availability can lag by tenant and region. Microsoft Learn says releases roll out over several days and new or updated functionality might not appear immediately. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/whats-new
3. Preview features must be labeled. The "What's new" page marks several July/June/May/April 2026 items as preview or production-ready preview; do not describe those as generally available unless the page says GA.
4. Generative orchestration is the default for new standard-harness agents, but prebuilt-agent configuration and admin policy can override what a maker sees. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-generative-actions
5. MCP support in Copilot Studio should be described as tools and resources support. Although MCP itself includes prompts, the Copilot Studio MCP article says Copilot Studio currently supports MCP tools and resources. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/agent-extend-action-mcp
6. Computer use is GA, but deployment mode matters. Microsoft guidance says hosted machines are for prototyping and BYO machines are for production scenarios. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/agent-tools
7. Automated evaluation is necessary but insufficient. Microsoft notes safety evaluators support responsible AI practices and governance but don't guarantee an agent is safe or appropriate for every scenario. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-intro
8. Lockbox has boundaries. Microsoft says Copilot Studio security audit logging and Agent 365 governance/audit events are not covered by configured Customer Lockbox. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/security-and-governance
9. Copilot Studio should not be positioned for emergency, clinical diagnosis, treatment, or medical device uses. Microsoft states the service is not intended or made available as a medical device, not a substitute for professional medical advice, and does not support emergency calls. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/fundamentals-what-is-copilot-studio
10. Do not imply customer approvals, endorsements, legal permissions, certifications, or production results beyond what the cited Microsoft sources state. This packet contains no fabricated approvals.
