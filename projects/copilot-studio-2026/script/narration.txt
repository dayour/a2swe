# CHAPTER 1 Managed agents
Microsoft Copilot Studio has moved beyond|the chatbot frame.
It is a low-code studio for building agents,|workflows, and agent flows that connect to business data|and publish where people already work.
With generative orchestration, an agent can choose|the right topic, tool, knowledge source, or other agent,|then ask for missing inputs and compose the response.
Tools turn intent into action: connectors, agent flows,|prompts, REST APIs, MCP, and computer use|for systems that still only expose a screen.
The enterprise story is control: data policies, audit,|Agent 365 visibility, Entra agent identities,|cost governance, and repeatable evaluations|before and after launch.
The executive takeaway: scale adaptive automation,|but run it like a managed business platform.
