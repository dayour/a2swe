# Artifact contracts

## Research

`research/research.md` MUST identify a source URL, access date, supported claim, qualification, and confidence. Screen and narration facts MUST be traceable to an entry.

## Narration

`script/narration.txt` MUST contain the approved English spoken text. Pronunciation adaptations MUST preserve meaning.

## Timeline

`script/timeline.json` MUST represent the synthesized or supplied audio timing used by subtitles and storyboard resolution. Total frame count MUST cover the encoded speech, lead, gaps, and tail.

## Subtitle module

`src/common/subs.ts` MUST expose cues synchronized to the authoritative timeline. Subtitle text MUST cover approved narration without adding unsupported claims.

## Storyboards

`script/storyboard_src.md` MUST contain resolvable sentence, chapter, and total timing tokens. `storyboard.md` MUST contain no unresolved tokens and MUST map visible scenes to registered shot IDs.

## Asset manifest

`asset-manifest.json` SHOULD be machine-readable and MUST record each non-generated external asset’s path, origin, license, digest, attribution, and use.

Evaluation asset bundles generated by the core include request and asset records,
the raster artifact, and an export `manifest.json`. Optional quality metadata MAY
record measured dimensions, contrast/readability signals, overlap findings, review
notes, and pending or completed human disposition. These fields are evidence
inputs only; they do not grant rights or production approval. Consumers MUST verify
the bundle `manifest.json` tamper status with the core verifier before treating the
bundle as intact.

## QC evidence

`qc/` MUST contain the applicable static, motion, frame, encoded-media, model, and human-review evidence. Empty inputs MUST NOT produce a passing result.

## Delivery index

`delivery.md` MUST link or name the release movie, Studio/source project, research, narration, timing, storyboard, QC, manifest, and companion. It SHOULD summarize encoded media properties and release status.

## Companion

`agent/SWE_AGENT.md` MUST remain portable, credential-free, current, and explicit about approvals, artifact verification, blockers, and next actions.
